# AGENTS.md

## 项目定位

本项目是一个轻量级 Python AI Agent 项目，用于学习、展示和面试准备。

项目可能包含以下模块：

- Workflow / Agent 编排
- LLM API 调用
- SQLite 持久化记忆
- RAG 检索增强生成
- Embedding 与向量检索
- MCP / FastMCP 工具调用
- 定时任务与 AI 热点日报生成

本项目的优先级是：

1. 正确性
2. 可读性
3. 可测试性
4. 可解释性
5. 面试可讲解性
6. 项目完整性
7. 项目工程性

---

## 总体工作规则

Codex 在处理本项目时必须遵守以下规则：

1. 每次只完成用户明确指定的任务，不要主动扩展需求。
2. 不要进行大规模重构，除非用户明确要求。
3. 修改代码前，必须先说明：
   - 对任务的理解；
   - 计划修改哪些文件；
   - 为什么需要修改这些文件；
   - 准备如何验证结果。
4. 只修改与当前任务直接相关的文件。
5. 如果认为必须修改额外文件，必须先说明原因，不要直接修改。
6. 不要改变已有公共接口，除非用户明确要求。
7. 不要删除已有功能，除非用户明确要求。
8. 不要为了让测试通过而随意修改测试。
9. 不要伪造测试结果。
10. 完成任务后，必须说明：
    - 修改了哪些文件；
    - 实现了什么功能；
    - 运行了哪些测试；
    - 是否存在失败测试；
    - 当前实现还有哪些限制。

---

## 安全规则

1. 不要读取、打印、修改或提交 `.env` 文件。
2. 不要硬编码 API key、token、password 或本地绝对路径。
3. 所有敏感配置必须通过环境变量读取。
4. 示例配置只能写入 `.env.example`。
5. 测试中禁止调用真实 LLM API。
6. 测试中禁止访问真实外部网络。
7. 测试中禁止写入真实业务数据库。
8. SQLite 测试必须使用临时数据库，例如 `tmp_path`。
