# 能力边界

本文档定义当前 Agent 的能力、适用场景和非目标，避免项目看起来像一个无边界的聊天机器人。

## 目标场景

- 采集多来源 AI 新闻，并生成中文 AI 应用热点日报。
- 从新闻级条目中聚合出事件级主题，减少重复报道和碎片化信息。
- 根据用户偏好筛选更重要的产品、应用、商业和开发者工具变化。
- 使用本地 SQLite 记录历史运行，支持事件级 RAG 和长期趋势回看。
- 对报告做质量自查，发现日期错误、无来源支撑事实、重复热点和结构问题。
- 输出运行状态、trace 和离线评估报告，便于复盘和迭代。
- 通过 MCP server 暴露工具能力，供支持 MCP 的客户端调用。

## 当前能力

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| RSS/网页资讯采集 | 已支持 | 支持主 RSS、备用 URL、主页 feed 自动发现和来源健康记录。 |
| 去重 | 已支持 | 基于链接和标题规范化去除重复新闻。 |
| 评分筛选 | 已支持 | 结合用户偏好、来源类别、关键词和反馈规则打分。 |
| 事件粗聚类 | 已支持 | 结合 embedding、实体、动作类型和关键词重叠。 |
| LLM 事件整合 | 已支持 | 使用模型合并候选事件并重命名。 |
| RAG | 已支持 | 优先事件级检索，失败后回退新闻级历史检索。 |
| 报告生成 | 已支持 | 两阶段 LLM 汇总，输出 Markdown 日报。 |
| 报告 critic | 已支持 | 本地硬规则 + LLM 质量检查。 |
| 自动修订 | 已支持 | critic FAIL 后触发修订，并用完整性闸门防止短输出覆盖报告。 |
| 离线评估 | 已支持，待增强 | 已有 run 级评分，下一步会汇总成功率、幻觉代理率、来源成功率等 KPI。 |
| MCP 工具 | 已支持 | 支持生成报告、评估、查询运行、查询报告等工具。 |

## 非目标

- 不承诺完全自动事实核验。模型输出仍需要对关键结论做人工抽查。
- 不负责生产级密钥管理、团队权限、多租户隔离或审计平台。
- 不直接发布报告到外部渠道。
- 不绕过用户授权执行危险文件操作。
- 不保证每个第三方资讯源长期稳定可用。

## 可靠性边界

该 Agent 的可靠性来自三层设计：

- 数据层：保存 raw data、SQLite、run state、trace 和 source health。
- 质量层：critic 检查、修订闸门、事件压缩率和离线评估。
- 人工层：关键报告结论和重大事实仍保留人工复核入口。
